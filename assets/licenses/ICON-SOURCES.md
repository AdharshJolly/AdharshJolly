# Icon and font sources

All icons are embedded inside the SVGs in `assets/`. Nothing is loaded from the network.

## Fonts (SIL Open Font License 1.1, subsetted, embedded as base64 WOFF2)
- Bricolage Grotesque (display) — see `OFL-BricolageGrotesque.txt`
- JetBrains Mono (mono) — see `OFL-JetBrainsMono.txt`
- Obtained from the `@fontsource` npm packages.

## Simple Icons (CC0 1.0) — see `SimpleIcons-CC0.txt`
Python, FastAPI, PyTorch, TypeScript, JavaScript, Next.js, React, Node.js, Express, MongoDB, Tailwind CSS, C, Git, GitHub.
Taken from simple-icons v16.35.0. Black-brand marks (Next.js, Express, GitHub) are drawn in off-white for the dark background.

## Marks not available in Simple Icons v16
Simple Icons removed these at the brand owners' request, and the official brand-center downloads could not be fetched here. These marks are trademarks of their owners and are used only to identify the technology or platform.
- AWS logo — Wikimedia Commons `Amazon_Web_Services_Logo.svg` (wordmark recoloured white for the dark background). Trademark of Amazon.com, Inc.
- Java logo — English Wikipedia `Java_programming_language_logo.svg`. Trademark of Oracle.
- LinkedIn "in" mark — Wikimedia Commons `LinkedIn_icon.svg`. Trademark of LinkedIn Corporation.

- React Native: no dedicated Simple Icons glyph; reuses the React atom (Simple Icons `react`) plus a small phone badge drawn for this profile.
